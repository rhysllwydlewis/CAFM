# GitHub labels

Created once before Stage 0. Colours follow the design system: Petrol for agents, graphite for metadata, status colours only for state.

| Label | Colour | Meaning |
|-------|--------|---------|
| `agent:A00` … `agent:A95` | `#136676` | Owning agent (one label per agent in doc 13) |
| `module:<slug>` | `#4D5562` | Module, matching the agent's module slug |
| `phase:0`, `phase:1`, `phase:2A`, `phase:2B`, `phase:3`, `phase:4`, `phase:5` | `#98A1AE` | Roadmap phase |
| `type:feature` | `#4199A7` | New capability from the feature catalogue |
| `type:bug` | `#B42D2D` | Something broken |
| `type:improvement` | `#78BCC6` | Better UX, performance, tests or clarity |
| `type:tech-debt` | `#656E7A` | Internal clean-up |
| `type:docs` | `#C1C8D1` | Documentation |
| `priority:now` | `#B42D2D` | Product owner wants this next |
| `priority:next` | `#C98410` | Soon |
| `priority:later` | `#D9DEE5` | Backlog |
| `blocked` | `#8F2424` | Cannot proceed; says what it waits for |
| `decision-needed` | `#C98410` | Needs a product-owner decision |
| `needs-design` | `#4199A7` | Needs a mockup before building |
